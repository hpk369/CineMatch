CineMatch

Hybrid movie recommendation engine built on Hadoop MapReduce. Implements three recommendation approaches — TF-IDF content similarity, co-occurrence collaborative filtering, and score-fusion hybrid — across 100K ratings.

How It Works

🎬

Content-Based

Builds a user taste profile by TF-IDF weighting genres across all rated movies. Recommends films with the highest cosine similarity to that profile. Runs as a 2-step MapReduce job.

TF-IDF · Genre Similarity
👥

Collaborative

Constructs a co-occurrence matrix across all users, then scores unrated movies by how often they appear alongside already-rated films. Two MapReduce passes: co-occurrence then scoring.

Co-occurrence Matrix
⚡

Hybrid

Multiplies content-based and collaborative scores for each (user, movie) pair. Surfaces movies that match your genre taste AND have strong co-occurrence signal — the best of both.

Score Fusion
